# QuantumCore Labs Website

Official static website for QuantumCore Labs, an independent software development brand.

**Live website:** https://quantumcore-labs.github.io/

## Website sections
- Home — company introduction and featured products
- Products — application catalogue and individual product pages
- Downloads — Android APK release links
- Resources — documentation and guides
- About — brand mission and focus
- Support — contact and help
- Legal — privacy policy, terms of service and account-data deletion information

## Tech stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Local preview
Open `index.html` in a browser, or run a local static server from the repository root.

## Maintenance
- Verify every APK release link before announcing a new version.
- Keep app descriptions, screenshots, supported Android versions and changelogs accurate.
- Update privacy disclosures whenever an app's data practices or third-party SDKs change.
- Never publish API keys, signing keys, passwords or private credentials in this public repository.
- This website describes QuantumCore Labs as an independent software development brand; it does not claim legal company registration.
